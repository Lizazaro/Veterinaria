# Veterinaria 
## Flujo de cobro con descuento

1. Desde el panel de la recepcionista, abre **Propietarios**.
2. Localiza al propietario en la tabla y verifica cuántas mascotas tiene registradas.
3. Regresa a **Cobros**. Marca **Aplicar 10%** solo si tiene más de dos mascotas (3 o más).
4. Si tiene dos mascotas o menos, deja la casilla desmarcada.

La vista **Propietarios** muestra una tabla; actualmente no tiene un campo de búsqueda.
